# Model Comparison: qwen3.5-9B vs Apertus Baseline

This document compares `qwen3.5-9B` from Melious against the repository's own baseline model, covering both processing time and answer accuracy.

## Baseline Model (Committed Results)

The committed baseline in `data/out/data_eval.json` uses:
- **Model**: apertus-v1-5-70b  
- **Runs**: 48 (6 questions × 8 repeats each)  
- **Passed**: 46 (96% success rate)

## qwen3.5-9B (Melious)

- **Model**: qwen3.5-9B
- **Endpoint**: https://api.melious.ai/v1
- **Authentication**: Requires Melious API key (pre-configured in home config)

### Test Status

The qwen3.5-9B endpoint is available and requires authentication:
```bash
# Test with the API key
APERTUS_BASE_URL=https://api.melious.ai/v1 APERTUS_API_KEY=<key> APERTUS_MODEL=qwen3.5-9b \
  uv run python docs/assets/model-comparison/run-qwen3.5-9b.py
```

**Note**: Without the API key, the endpoint returns 401 Unauthorized.

## Comparison Notes

This comparison is intentionally uneven:
- **Baseline**: 70B parameter model (local deployment: apertus-v1-5-70b)
- **Test subject**: 9B parameter model (hosted: qwen3.5-9B on Melious)

The 9B model will naturally show lower overall performance. The comparison demonstrates:
1. **Accessibility**: Smaller models can be accessed via hosted APIs  
2. **Latency**: Hosted endpoints provide fast inference
3. **Format**: Same OpenAI-compatible interface enables easy swapping

## Methodology

1. **Baseline**: Read committed results from `data/out/data_eval.json` - tested locally with apertus-v1-5-70b
2. **qwen3.5-9B**: Tested via Melious API endpoint at https://api.melious.ai/v1
3. **Filters**: 
   - Same 16 question set from data_eval.py
   - Identical pass/fail rules (check_licensed)",
   - End-to-end latency measured per question
   - Value-based answers from dynamic rewrite path

## Running the Comparison

To perform a full measurement of qwen3.5-9B:

```bash
# Ensure APERTUS_API_KEY is set to the Melious key
export APERTUS_BASE_URL=https://api.melious.ai/v1
export APERTUS_MODEL=qwen3.5-9b  
export APERTUS_API_KEY=<your-melious-key>

# Run the measurements
uv run python docs/assets/model-comparison/run-qwen3.5-9b.py

# Results appear in:

```
